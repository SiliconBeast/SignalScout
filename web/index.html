The simulator walks through first-boot setup. Wi-Fi joins a simulated network called "HackerspaceYEG", so weather and updates have data. The mesh peer B7C4 sends a message every few seconds, and waypoints are preloaded. Button layout follows the rev C5 enclosure caps; proportions are approximate.
