# SOS and safety behaviour

- Hold the SOS button for 2 seconds to start SOS. Hold again to cancel.
- While SOS is active the position is broadcast to the mesh every 20 seconds and the siren sounds.
- SOS works from any screen and with the lock switch on.
- The LoRa mesh is peer to peer. Messages only reach people within range of the mesh, so this is not a replacement for a satellite messenger or emergency services.
