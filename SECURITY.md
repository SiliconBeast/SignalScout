# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting for this repository (Security tab, "Report a vulnerability"), or contact the maintainer directly.

## Scope

- Firmware: the over-the-air update path, the Console web hotspot, and the pogo-link and LoRa message parsers.
- Hardware: design problems that could cause unsafe behaviour (battery charging, power rails).

Nothing in this repository has run on production hardware yet, so treat all builds as prototypes.
